## 📖 Overview

Standard cartographic tools and travel databases typically present geographic data as static maps, flat text tables, or disconnected search listings. 

**Bangladesh InSight 360°** reimagines how national geography, architecture, rivers, and cultural legacy are experienced online. It establishes a unified visual architecture combining:

- **True Fullscreen Edge-to-Edge Panoramas**: Seamless, unclipped panoramic views across all 8 administrative divisions.
- **Dynamic Mode-Calibrated Hotspots**: Interactive floating markers whose coordinates physically shift between Day and Night views to align precisely with illuminated structures, bridges, rivers, and monuments.
- **Deeply Researched Heritage Database**: Over 64 verified historical landmarks with establishment eras, architectural styles, districts, and detailed historical contexts.
- **UNESCO Intangible & Tangible World Heritage Archive**: Complete documentation of UNESCO-recognized milestones including International Mother Language Day, Pahela Baishakh Mangal Shobhajatra, Jamdani Weaving, Shital Pati, Dhaka Rickshaw Art, Baul Songs, and historic monuments.
- **Verified National Superlatives**: Authoritative records spanning Bangladesh's extreme cardinal borders (North, South, East, West), largest villages, river networks, and natural phenomena.

🔗 **Repository:** [https://github.com/Shreyalien/Bangladesh-InSight.git](https://github.com/Shreyalien/Bangladesh-InSight.git)

## ✨ Core Capabilities

### 1. 🌐 Fullscreen Edge-to-Edge Panoramic Stage
- **Zero-Crop Cinematic Viewport**: Engineered to span 100% of the viewport width and height without boxed container constraints or navigation header overlap.
- **One-Click Instant Perspective Swap**: Clicking directly on the panoramic stage immediately cycles through available angles and daytime/nighttime captures.
- **Automated Slideshow Engine with Neon Progress Line**: Smooth 4-second cross-dissolve transitions on the national home showcase, synchronized with a real-time reactive progress indicator bar.

### 2. ☀️🌙 Mode-Calibrated Spatial Pinning (Day & Night)
- Distinct coordinate matrices (`visualMarkersDay` and `visualMarkersNight`) calibrated to physical features in each photograph.
- Toggling between Day Mode and Night Mode dynamically relocates pins to match shifted angles, night illumination points, illuminated cable-stayed bridges, lit minarets, and river channels.
- Glassmorphic floating pins featuring subtle floating vertical oscillation (`markerFloat`), frosted backdrop blur (`backdrop-blur-xl`), and radiant category borders.

### 3. 🔍 Universal Multi-Entity Search Engine
- High-performance, zero-dependency client-side search indexing across four distinct data dimensions:
  - **Divisions**: Instant matching on English names, Bengali names, and regional taglines.
  - **Landmarks & Heritage**: Instant lookup for ancient viharas, Mughal forts, colonial palaces, mosques, and engineering feats.
  - **Districts**: Full search across 64 districts by name, headquarters (HQ), river systems, and famous culinary items.
  - **Rivers & Waterways**: Deep search indexing across major deltaic river systems.

### 4. 📚 Comprehensive 64-District Encyclopedia
- Structured matrix of all 64 sovereign districts of Bangladesh.
- Each entry includes administrative division, geographic area (km²), district headquarters, constituent upazilas, river networks, and local delicacies.
- Contextual modal inspections without arbitrary image fallbacks, rendering clean administrative badges, geographic coordinates, and historical context.

### 5. 🎨 Bespoke Sovereign Brand Identity
- Custom vector emblem pairing Bangladesh's emerald-and-crimson national colorway with the golden National Flower (*Shapla / Water Lily*) encased within an interactive 360° compass ring.

## 🏛️ UNESCO World Heritage & National Observances

Bangladesh InSight hosts a dedicated sovereign records portal documenting international cultural recognitions:

| Year | Milestone / Heritage | UNESCO Classification | Key Cultural & Historical Significance |
|:---|:---|:---|:---|
| **1999** | **International Mother Language Day (21 Feb)** | Global Recognition | Declared by UNESCO on 17 Nov 1999 honoring the 1952 Language Movement Martyrs of Dhaka. |
| **2016** | **Mangal Shobhajatra on Pahela Baishakh** | Intangible Cultural Heritage | Inscribed as Intangible Cultural Heritage of Humanity; secular celebration of unity, peace, and renewal. |
| **2013** | **Traditional Art of Jamdani Weaving** | Intangible Cultural Heritage | Bangladesh's 1st Geographical Indication (GI) product; surviving heirloom of legendary Dhaka Muslin. |
| **2023** | **Dhaka Rickshaws & Rickshaw Painting** | Intangible Cultural Heritage | Inscribed in Dec 2023 at the 18th UNESCO session, celebrating urban folk art, floral motifs, and craftsmanship. |
| **2017** | **Traditional Art of Shital Pati Weaving** | Intangible Cultural Heritage | Centuries-old artisanal craft of weaving smooth natural cane reeds (*Murta*) across greater Sylhet. |
| **2005** | **Baul Songs & Mysticism of Lalon** | Masterpiece of Oral Heritage | Inscribed as a Masterpiece of Oral and Intangible Heritage, celebrating the humanist folk philosophy of Fakir Lalon Shah. |
| **1997** | **The Sundarbans Mangrove Sanctuary** | World Natural Heritage | Largest contiguous tidal halophytic mangrove forest on Earth; global sanctuary for the Royal Bengal Tiger. |
| **1985** | **Historic Mosque City of Bagerhat** | World Cultural Heritage | 15th-century brick architectural marvel built by Khan Jahan Ali, featuring the 77-domed Sixty Dome Mosque. |
| **1985** | **Ruins of the Buddhist Vihara at Paharpur** | World Cultural Heritage | Somapura Mahavihara; 8th-century Pala Empire monastic university, one of the largest intellectual centers in Asia. |
| **1971** | **National Independence & Victory Days** | Sovereign National Observances | 26 March (Independence Day) & 16 December (Victory Day) commemorating the sovereign birth of the Republic. |

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### 1. Installation

Clone the repository and install all dependencies:

```bash
# Clone the repository
git clone https://github.com/Shreyalien/Bangladesh-InSight.git

# Navigate into project directory
cd Bangladesh-InSight

# Install root & backend dependencies
npm install

# Install client frontend dependencies
cd client
npm install
cd ..
```

### 2. Development Mode

Launch the local development environment with Vite HMR:

```bash
# In the client directory
cd client
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### 3. Production Build & Execution

To generate the optimized production bundle and serve it through the Express static host:

```bash
# Build production client bundle
cd client
npm run build
cd ..

# Start the production Express server
node server/index.js
```

The production application will be live at `http://localhost:5000`.
