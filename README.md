## 🚀 Key Features & Highlights (মূল বৈশিষ্ঠ্যসমূহ)

### 1. 🌓 Dual Mode National Overview (Day & Night)
- **Day Mode (রূপসী বাংলা):** Golden daytime deltas, lush green riverscapes, river birds chirping.
- **Night Mode (নিশাচর বাংলা):** Illuminated skylines, tranquil night rivers, glowing cricket rhythm.

### 2. 🧭 8 Divisional 360° Interactive Panoramas
- Complete panoramic viewports for all 8 divisions:
  - **Dhaka (ঢাকা):** Ahsan Manzil, Lalbagh Fort, Shahid Minar, Tara Masjid, Curzon Hall, National Parliament, Panam Nagar.
  - **Chattogram (চট্টগ্রাম):** Sajek Valley, Cox's Bazar, Saint Martin's Island, Kaptai Lake, Naval Academy, Chandranath Hill.
  - **Rajshahi (রাজশাহী):** Varendra Museum, Bagha Mosque, Somapura Mahavihara, Puthia Palace, Padma River Border.
  - **Khulna (খুলনা):** Sixty Dome Mosque (Bagerhat), Sundarbans Mangrove Forest, Mujibnagar Memorial, Khan Jahan Ali Mazar.
  - **Sylhet (সিলেট):** Ratargul Swamp Forest, Jaflong Stone River, Shah Jalal Dargah, Sreemangal Tea Gardens, Bichanakandi.
  - **Barishal (বরিশাল):** Kuakata Sea Beach, Floating Guava Market, Durga Sagar Lake, Guthia Mosque.
  - **Rangpur (রংপুর):** Kantaji Temple (Dinajpur), Tajhat Palace, Swapnapuri, Ramsagar Lake.
  - **Mymensingh (ময়মনসিংহ):** Shashi Lodge, Birishiri Ceramic Hills & Turquoise Lake, Muktagacha Rajbari, Garo Hills.
- Interactive drag/pan, zoom in/out (0.7x to 1.8x), reset view, and radar pulsing hotspots.

### 3. 📖 Complete 64-District Encyclopedia (৬৪ জেলা এনসাইক্লোপিডিয়া)
- 100% verified administrative details for every single district in Bangladesh.
- English and Bengali names, area in km², population, river networks, landmark destinations, and travel tips.

### 4. 🍯 Traditional Foods & GI-Certified Sweets (ঐতিহ্যবাহী খাবার ও মিষ্টি)
- District-wise legendary delicacies:
  - **Bogura:** Bogra Doi (বগুড়ার দই - GI Certified)
  - **Natore:** Natore Kachagolla (নাটোরের কাঁচাগোল্লা - GI Certified)
  - **Mymensingh (Muktagacha):** Muktagacha Monda (মুক্তাগাছার মণ্ডা)
  - **Tangail (Porabari):** Porabari Chamcham (পোড়াবাড়ীর চমচম - GI Certified)
  - **Cumilla:** Comilla Rasmalai (কুমিল্লার রসমালাই)
  - **Chattogram:** Mezban Gosht & Kala Bhuna (মেহেরবানি ও মেজবানি মাংস)
  - **Sylhet:** Shatkora Beef & 7-Layer Sreemangal Tea (সাতকড়া ও সাতরঙা চা)
  - **Khulna/Bagerhat:** Chui Jhal Gosht (চুই ঝাল মাংস)
  - **Barishal:** Hilsa Paturi & Amra (ইলিশ পাতুড়ি ও আমড়া)
  - **Rajshahi:** Fazli Mangoes & Raghobshahi Sweets (ফজলি আম ও মিষ্টি)

### 5. 🎵 Procedural Web Audio API Ambiance
- Real-time procedural audio synthesis without external mp3 dependencies (river/bird daytime ambiance and crickets night ambiance).

### 6. 🗺️ Custom Trip Planner & Interactive Heritage Quiz
- Multi-day trip itinerary generator with printable itinerary cards.
- 10-question trivia quiz with live scoring, historical explanations, and confetti celebrations.

### 7. ⌨️ Global Search (Ctrl + K)
- Instant fuzzy search across divisions, districts, delicacies, and archaeological sites.

## 🛠️ Quick Installation & Setup Guide (রান করার নিয়ম)

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v8 or higher)

### Step 1: Clone or Extract the Project
```bash
cd amar-desh-360
```

### Step 2: Install Server Dependencies
```bash
cd server
npm install
cd ..
```

### Step 3: Install Client Dependencies
```bash
cd client
npm install
cd ..
```

### Step 4: Run the Application
In one terminal, start the Backend API:
```bash
cd server
node index.js
# API running on http://localhost:5000
```

In a second terminal, start the Frontend Vite Dev Server:
```bash
cd client
npm run dev
# Frontend live on http://localhost:5173
```

Alternatively, to build for production:
```bash
cd client
npm run build
```
